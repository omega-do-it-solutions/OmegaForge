# راهنمای عمومی OmegaForge

این مخزن در شاخهٔ `manual` یک وب‌سایت عمومی، ساده و دوزبانه برای کاربران با هر
سطح تجربهٔ فنی است. راهنمای فارسی و انگلیسی به تازه‌کارها مسیر آماده می‌دهد و
به مهندسان کمک می‌کند AI را با context، قراردادها و skillهای قابل‌اعتماد در
workstation خود به کار بگیرند.

فارسی و انگلیسی فقط زبان‌های ارائهٔ این راهنما هستند و محدودیتی برای خود
OmegaForge ایجاد نمی‌کنند؛ کاربر می‌تواند گفتگو با دستیار هوش مصنوعی را به هر
زبانی که آن دستیار پشتیبانی می‌کند ادامه دهد و پاسخ را به همان زبان دریافت کند.

بخش «دربارهٔ ما» نیز معرفی کوتاهی از Omega Do، مسئله‌ای که به ساخت OmegaForge
منجر شد و روشی که این قالب برای همکاری مطمئن با هوش مصنوعی انتخاب کرده ارائه
می‌دهد.

راهنما همچنین پیش‌نیازهای سادهٔ شروع، مسیر قابل‌انتظار پس از ارسال prompt،
پرسش‌های رایج، مرز حریم خصوصی، نسخه و زمان آخرین بازبینی و راه‌های مشارکت عمومی
از طریق GitHub را نمایش می‌دهد.
نسخهٔ فعلی راهنما `v0.1.0` است و تغییرات آن در
[`apps/web/CHANGELOG.md`](apps/web/CHANGELOG.md) ثبت می‌شود؛ `CHANGELOG.md` ریشه فقط
تاریخچهٔ خود OmegaForge را نگه می‌دارد.

وب‌سایت هیچ حساب کاربری، پایگاه داده، فایل آپلودی یا اتصال مستقیم به سرویس‌های
هوش مصنوعی ندارد.

## پیش‌نیازها

- Node.js 20.19 یا جدیدتر
- pnpm 11.11 یا جدیدتر

## اجرای محلی

```sh
pnpm install
pnpm dev
```

سپس وب‌سایت را در `http://localhost:5173` باز کنید.

## بررسی و ساخت

```sh
pnpm lint
pnpm typecheck
pnpm check
pnpm build
pnpm --filter @omega-forge/handbook preview
```

خروجی استاتیک تولیدشده در `apps/web/dist` قرار می‌گیرد. دستور `preview` فقط برای
بررسی محلی خروجی تولید است و سرویس تولید نیست.

## پیکربندی محلی

یک `.env.example` در ریشهٔ مخزن وجود دارد. برای توسعهٔ محلی، در صورت نبودن فایل
`.env`، آن را از نمونه بسازید:

```sh
cp .env.example .env
```

وب‌سایت راهنما متغیر محیطی یا راز مخصوص به خود ندارد. مقادیر موجود در `.env`
فقط برای پروفایل اختیاری SeaweedFS در قالب OmegaForge هستند؛ راهنمای فعلی از آن
استفاده نمی‌کند. `.env` را commit نکنید.

## استقرار

Cloudflare Pages باید به مخزن GitHub متصل شود و شاخهٔ `manual` را به‌عنوان
Production branch دریافت کند. در تنظیمات پروژه این مقادیر را وارد کنید:

```text
Root directory: /
Build command: pnpm install --frozen-lockfile && pnpm check && pnpm build
Build output directory: apps/web/dist
```

پس از هر push به `manual`، Cloudflare Pages ساخت و انتشار نسخهٔ جدید را انجام
می‌دهد. اتصال زیردامنه و مجوزهای Cloudflare یک کار عملیاتی جداگانه است و هیچ
کلید یا رازی در این مخزن نگه‌داری نمی‌شود.

## نگه‌داری محتوا

`main` منبع قالب OmegaForge است و با `manual` ادغام نمی‌شود. هنگام تغییر قواعد
یا skillهای OmegaForge در `main`، محتوای فارسی و انگلیسی و promptهای شاخهٔ
`manual` را متناسب با آن به‌روزرسانی کنید.
