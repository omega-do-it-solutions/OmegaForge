# OmegaForge Support

## Start With The Manual

The [OmegaForge manual](https://forge.omegado.com) provides the step-by-step
workflow for creating a project, preparing product details, running bootstrap,
updating an existing foundation, and recovering from common problems.

## Ask For Help

Use the repository's issue templates for:

- reproducible OmegaForge behavior that conflicts with its documentation;
- unclear or incorrect documentation;
- compatibility problems in an OmegaForge-owned skill or workflow; and
- proposals that improve the reusable foundation.

Include the OmegaForge version or commit, coding agent, operating environment,
relevant command or prompt, expected outcome, and actual outcome. Remove all
credentials, private prompts, customer data, and unrelated application code.

OmegaForge support does not replace support for a generated project's framework,
hosting provider, infrastructure, or production operations. Report those issues
to the project or provider that owns them.

Security concerns must be reported privately according to
[SECURITY.md](SECURITY.md), never through a public support issue.
